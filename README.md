# Geospatial AI Analysis of Desertification in India

Interactive web page analysing desertification / land degradation trends in India since 2000, using
ISRO-SAC Desertification and Land Degradation Atlas data (2003-05, 2011-13, 2018-19) and a simple
linear-regression model that runs in the browser.

**Course:** CHE110 Environmental Studies, Lovely Professional University
**Team:** Arhaan Khan, Ansh Dewanji, Sangam

## Run locally
It is a single static page with no build step. Open `index.html` in a browser.

## Deploy on Render
1. Render dashboard -> New -> Static Site -> connect this repository.
2. Build command: leave empty. Publish directory: `.`
(`render.yaml` already contains these settings, so you can also use New -> Blueprint.)

## Data note
Figures are taken from the ISRO-SAC atlases and are indicative; verify against the original publications.
